## 1. Executive Summary & Ground-Truth Leakage Audit

During initial validation, a critical integrity vulnerability was identified: candidate road nodes for the Map Matching experiment were generated by downsampling the future reference GPS trajectory (`ref_e[:start_idx+1250:5]`). This constituted ground-truth leakage and produced artificial 120s accuracy ($18.98\text{m}$).

**Corrective Actions Taken:**
1. **Map Matching Module Isolated:** In strict compliance with Problem Statement Rule 5, Map Matching is classified as **OFFLINE EXPERIMENTAL ONLY**. It is completely excluded from the production dead reckoning engine and primary benchmark matrix unless independent GIS/OSM vector polylines are supplied.
2. **Autonomous Physical IMU ZUPT:** Implemented pure physical IMU-invariant standstill detection ($\sigma^2(a) < 0.015\text{ m}^2/\text{s}^4$, $\|\boldsymbol{\omega}\| < 0.02\text{ rad/s}$, 8-sample persistence) with zero velocity parameters.
3. **Audited Autonomous Dead Reckoning:** Re-benchmarked 100% leak-free autonomous navigation pipelines across 10s, 30s, 60s, and 120s horizons on `IOVNBD_S3c`.

## 3. ZUPT Episode Trigger Analysis (120s Window)

## 4. Final Production Architecture

- **Sensor Frame Axis:** $- \text{gyro}_y$ (vertical vehicle yaw rate for upright dashboard-mounted phone)
- **Neural Model:** Frozen Exp_5 PyTorch LSTM Delta-V Checkpoint with training-fitted MinMax normalization
- **Active Drift Modules:**
  - Online Pre-Outage Gyro Bias Subtraction (Active)
  - 1D Extended Kalman Filter Velocity Fusion (Active)
  - Safe Physical IMU-Invariant ZUPT (Active)
  - Non-Holonomic Lateral Velocity Damping (Active)
  - Map Matching: **OFFLINE / DISABLED in Autonomous Production Pipeline**
